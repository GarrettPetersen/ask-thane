Thane Chat install

Start terminal chat in a few commands.

Install the CLI, run the guided setup, and open a channel. The free tier supports 100 members and 10 private channels.

$ npm install -g @ask-thane/thane-cli
$ thane init
$ thane chat general

Setup

1. Install the CLI

Install globally with npm, then run thane init. The setup asks for your email and verifies the account.

2. Create a workspace

Create the first workspace for your organization or join one from an invite link.

3. Open chat

Run thane chat general for the live interface, or use scriptable commands for agents and automation.

Common Next Steps

Invite Teammates

Use thane invite teammate@example.com to send a workspace invite.

Import a Slack Export

Workspace admins can run thane workspace create-from-slack ./export.zip --apply.

Connect Ask Thane

Teams using the agent can enable the bridge with thane ask-thane enable.
