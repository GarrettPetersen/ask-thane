Subprocessors

Last updated: May 14, 2026

Ask Thane uses the following subprocessors to operate the service.

Provider Purpose Data Categories
Cloudflare Hosting, edge runtime, and database infrastructure Application data and operational metadata
Slack Messaging platform integration Message content, channel metadata, workspace and user identifiers
OpenAI LLM inference for task and reminder intelligence Prompted message/task context and metadata necessary for inference
Anthropic (optional) Alternative LLM inference provider when configured Prompted message/task context and metadata necessary for inference
Stripe (when billing enabled) Payment processing and usage-based billing Billing identifiers, metered usage totals, and payment metadata

Updates

We may update this list as infrastructure changes. Material additions will be reflected on this page.
