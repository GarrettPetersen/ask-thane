Thane Chat Setup

  1. Install with npm install -g @ask-thane/thane-cli.
  2. Run thane init and enter your email when prompted.
  3. Create or select a workspace, then open chat with thane chat general.
  4. To migrate, export a Slack workspace ZIP and run thane workspace create-from-slack ./export.zip --apply.
  5. Invite teammates with thane invite teammate@example.com.
  6. Upgrade with thane billing checkout for more members or private channels.

Ask Thane Setup

  1. Approve Slack OAuth so Ask Thane can join the workspace.
  2. For paid tiers, continue to Stripe checkout.
  3. After install, invite Thane to channels with /invite @Thane.
  4. Assign work in channel or DM and Ask Thane will track it.
  5. In Thane Chat, enable the bridge with thane ask-thane enable and mention @thane.
